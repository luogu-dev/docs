# 图床使用规则

1. 用户上传图片时必须遵守相关法律法规，不得上传以下类型的图片：

- 含有色情、暴力、宣扬恐怖主义的图片
- 涉政图片
- 侵犯版权、未经授权的图片
- 其他违反法律法规和公序良俗的图片

2. 用户需实名认证后才能使用图片上传功能。

3. 图床功能仅限洛谷站内交流及学术功能（比赛、题目等）使用，全图床开启反盗链功能，故无法作为一般的共享图床在站外使用。所以我们对用户所上传的图片暂定做如下限制：
   - 单张大小不超过 500KB 且添加水印的图片：无总数量限制，为防范滥用，24 小时内最多可上传 50 张。
   - 满足以下任一条件的图片：单张大小超过 500KB 且小于 3MB，或不添加水印，将根据上传时的咕值限制总存储空间：咕值≤150 的用户总空间限制为 10MB，咕值>150 的用户总空间限制为 50MB。
   - 禁止上传单张大小超过 3MB 的图片。

4. 图片会转换为最佳格式并进行一定压缩处理，但不保证转换后的图片大小小于原始图片大小。

5. 违反上述规则者，将按照洛谷社区规则进行处理惩罚。
